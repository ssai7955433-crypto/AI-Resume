# Sai's Resume Studio

A free, responsive resume builder with a live preview. Enter your information, add work and education entries, and print or save the finished resume as a PDF from your browser.

## Use it

Open `index.html` in a modern browser, or serve this directory with any static web server. No build step or account is required.

Your draft is stored in the browser's local storage on the current device. It is not uploaded to a server. Use **Print / Save PDF** and choose the PDF destination in your browser's print dialog.

## GitHub Pages

The included GitHub Actions workflow deploys the site to GitHub Pages when changes are pushed to `main`. After the first successful deployment, the site will be available at:
